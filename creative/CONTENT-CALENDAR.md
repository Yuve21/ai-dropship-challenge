## How to read this table

- **Allowed post type** comes straight from the Track A table in `docs/WARM-UP.md`, never invented here.
- **Asset** is the exact script filename in `creative/scripts/`. Where a slot uses an already-existing
  script (the two full scripts inside `day1-hook-bank.md`), that's stated explicitly rather than implied.
- **CTA rung** cites `docs/NO-STALL.md` P6, the CTA Ladder used under the ~1,000-follower link gate. Every
  slot in this calendar uses **Rung 1 (pinned comment)** because the account will have close to zero
  followers through this whole window; no slot claims TikTok Shop eligibility (Rung 2), which is not
  connected as of 2026-08-12.
- **AIGC label state** is "not applicable" everywhere in this calendar because every script recommends real
  phone-filmed UGC, not AI-generated video (per each script's Format recommendation section). If AI-
  generated B-roll is ever substituted in, TikTok's AIGC disclosure label becomes required before that post
  ships, and this column must be updated to say so for that specific post.
- Native/non-promotional days (-4 to -1) carry **no CTA and no AIGC concern by protocol rule**: no product
  is pitched, so there is nothing to route anyone to.

## The Dashboard-and-Pointer vs Standard-UGC A/B test, set up to actually run

Per `docs/LEARNINGS.md` (2026-08-12): *"The test that settles both: 3 dashboard-and-pointer videos against 3
standard UGC-style videos in the same week, compared on hook rate and comment rate."* Here is that test,
scheduled for real.

**Arm B: Standard UGC, Result-First family** (the account's original proven structure: Hook -> Problem ->
Demo -> Benefit -> Proof -> CTA)
1. `day1-hook-bank.md`, Full Script 1, "My cat wouldn't drink water until I got this.", posts 2026-08-18, 7:00 PM
2. `day1-hook-bank.md`, Full Script 2, "three weeks...still staring at it.", posts 2026-08-19, 7:00 PM
3. `day3-script-nobody-told-me.md`, posts 2026-08-20, 11:00 AM

**Both arms complete inside the same week**, 2026-08-18 through 2026-08-21 (Challenge Days 1-4), as the
learning entry requires.

**Read window:** hook rate and hold rate per video at 24-72h, per `creative-director`'s standing gates
(hook rate target above 30%, hold rate above 10%). Comment rate read at the same 72h mark per video, then
averaged per arm once all 6 videos have at least 72h of data, which lands by 2026-08-24 (Challenge Day 7) at
the latest.

**Confound, named rather than hidden:** Arm A airs in the day's first (11:00 AM) slot in all three
instances. Arm B airs at 7:00 PM in two of its three instances and 11:00 AM in the third. This is a
byproduct of fitting exactly 3-vs-3 across Days 1-3's two-slot cadence without disturbing the pre-existing
hook-bank scripts, not a deliberate confound control. If `growth-operator`'s daily reads show a real
time-of-day effect on this account in general, that has to be ruled out before crediting any hook-rate or
comment-rate gap between the two arms to the format itself rather than the posting hour.

**What decides it:** if Arm A's mean hook rate and comment rate both beat Arm B's mean by a real margin (not
noise at n=3 per arm), `creative-director` promotes Dashboard-and-Pointer from `HYPOTHESIS` to a live entry
in `docs/LEARNINGS.md` under *Hooks and creative*, confidence Low (n=3 per arm, one account, one week), and
schedules more of it. If it loses or reads flat, that's written up as a real result too, not quietly dropped.

## The comment-bait lever, tested across the whole week, not only inside the A/B

Every Challenge Day 1+ script in this run carries a stated **Comment-bait element** section (see each script
file). Per the `docs/LEARNINGS.md` 2026-08-12 finding (a 12x comment-rate spread between two posts on the
same external account, tracked separately from format), four different comment-bait prompt *shapes* are
deliberately spread across the 9 scripted Day 1-4 posts so the lever itself gets read, not just one prompt's
wording:

| Prompt shape | Scripts using it | Example |
|---|---|---|
| Closed two-option poll | `day2-script-dashboard-first-sip.md`, `day3-script-bowl-or-fountain-debate.md` | "team drinks-from-the-tap or team-ignores-the-water-bowl" / "comment BOWL or FOUNTAIN" |
| Match-my-experience recognition | `day1-script-dashboard-pump-on.md`, `day4-script-pov-still-full.md`, both Full Scripts in `day1-hook-bank.md` (retrofitted) | "comment (paw emoji) if your cat ignores her water bowl too" / "comment 'still full' if this is your house too" |
| Open-ended, no product ownership required | `day4-script-dashboard-quiet-check.md` | "comment the loudest thing in your house right now" |
| Single-emoji, lowest possible friction | `day4-script-silent-comparison.md` | "comment the emoji that matches your cat's bowl right now" |

There is no internal baseline yet (zero posts exist on this account as of 2026-08-12), so the only
comparison point is the external one already in `docs/LEARNINGS.md`. Once this week's data lands, log actual
comment rate per prompt shape to `docs/LEARNINGS.md` under *Hooks and creative*, separately from the
Dashboard-and-Pointer format verdict, since the two levers are explicitly meant to be read apart.
